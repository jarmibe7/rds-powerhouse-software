# Core
#### Authors: Cole Abbott, Heinrich Asbury, Jared Berry, Evan Bulatek, and Benji Sobeloff-Gittes

This C++ package contains code for interfacing with our electronics/hardware, and controlling the finger.

#### Software Structure
* apps/ - Contains all executables.
* include/finger/ - Contains a library `finger` for the interface/control software suite (.hpp files).
* src - Contains implementations for the finger library.
* tests - Contains `catch2` style tests.
